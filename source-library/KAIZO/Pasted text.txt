1. System Architecture Overview & Core Engines
The system is structured around the KAIZO Core Engine, governing 7 decoupled, high-performance sub-engines:

Knowledge Engine: Enforces the strict pipeline: Collect -> Verify -> Classify -> Link -> Approve -> Publish for all 9 data domains (Technique, Drill, Problem, Solution, Test, Article, Video, Research, Exercise).

Rule Engine: Dynamic rule evaluation library separating logic from code.
Decision Engine: Real-time tatami-side or administrative decision support.
Recommendation Engine: Proactive training loads, recovery, and intervention suggestions.
Planning Engine: Season, weekly, and daily structural training periodization.
Analytics Engine: Deep performance metrics and evolutionary tracking.
Learning Engine: Continuous system optimization based on past outcomes.
