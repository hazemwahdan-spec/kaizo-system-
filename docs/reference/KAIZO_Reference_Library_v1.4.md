## 2. R-Level Definitions
- **R5 — Production / Operationally Verified Reference:** complete, operationally proven, strong evidence.
- **R4 — Verified / Approved Reference:** complete, documented, verified, but less production proof than R5.
- **R3 — Structured / Applied Reference:** organized and reusable, but lower verification.
- **R2 — Structured Reference:** organized but limited verification.
- **R1 — Informational Asset:** useful information but not a strong operational reference.

**Important:** R-Level measures evidence strength/reliability, not strategic importance.
