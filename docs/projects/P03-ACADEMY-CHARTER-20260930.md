# KAIZO P03 — Academy Management — Project Charter
Date: 2026-09-30
Status: OPEN / IMPLEMENTATION

## Objective
Create the first Academy-level operational workspace as a separate application layer above the frozen KAIZO Core, Coach, and Technical Director surfaces.

## Scope
- Academy identity and operating snapshot.
- Teams/groups and coaches as operational records.
- Program/calendar overview.
- Technical/coach oversight summary using currently available runtime signals.
- Academy risk/attention register as a governed workspace view.
- Read-only governance indicators.
- Explicit boundaries and future dependencies.

## Non-scope
- Production authentication/RBAC (P13 hard gate).
- Minor/guardian consent (P14 hard gate).
- Durable longitudinal athlete database (P05/P15).
- Financial/CRM/payroll.
- Video/wearable/competition integrations.
- New Core decision logic.
- Claiming authoritative academy-wide KPIs where no durable source exists.

## User stories
- Academy Director can see academy operating structure.
- Academy Director can see teams, coaches and programs in one workspace.
- Academy Director can identify technical attention items without overriding Coach/Technical authority.
- Academy Director can distinguish entered operational information from verified Core evidence.
- Academy Director can see Core/runtime governance status.

## Acceptance
Implemented + deployed + tested + independently retested + evidence archived. No capability is marked authoritative where persistence, identity, or evidence is absent.
