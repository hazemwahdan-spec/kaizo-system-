# KAIZO P02 — Technical Director Workspace — Project Charter

Date: 2026-09-30
Status: OPEN / IMPLEMENTATION

## Objective
Create a Technical Director workspace as a separate application layer above the frozen KAIZO Core and the completed P01 Coach workspace.

## Scope
1. Technical methodology/program review visibility.
2. Coach decision-cycle visibility using existing Core audit data.
3. Governed review/approval record for technical oversight.
4. Case/athlete/coach context view using currently available Core data.
5. Core health and evidence-state visibility.
6. Explicit boundaries: no scientific claim promotion, no Core rebuild, no role/permission activation, no persistent longitudinal athlete database.

## Non-scope
- Production RBAC/authentication (P13).
- Minor/guardian consent (P14).
- Longitudinal persistent athlete record (P05).
- Academy management (P03).
- New decision-engine logic.
- Video, wearable, competition integrations.

## User stories
- As Technical Director, I can see the current Core health and governance state.
- As Technical Director, I can inspect audit events relevant to coaching decisions.
- As Technical Director, I can review a coach decision cycle and record a governed oversight note.
- As Technical Director, I can distinguish operational evidence from unvalidated claims.
- As Technical Director, I can preserve Coach Final Authority while exercising technical oversight.

## Acceptance criteria
P02 closes only when the workspace is implemented, deployed, tested, independently retested, evidenced, and archived.
