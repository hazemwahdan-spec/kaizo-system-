# KAIZO ACADEMY — P03

Academy-level operational workspace layered above the frozen KAIZO Core.

This version provides an operational UI for academy snapshot, teams/groups, programs/calendar, attention items, Core health, and audit visibility.

Important governance boundary:
- Browser-local records are workspace inputs, not authoritative durable academy records.
- Production RBAC/authentication remains P13.
- Minor/guardian consent remains P14.
- Durable longitudinal persistence/scalable analytics remain P05/P15.
- No new Core decision logic is introduced.
- No academy-wide KPI claim is made without durable evidence.
